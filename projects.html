Prompt Chaining for Negative Test Case Generation

View on GitHub

A specialized Python implementation utilizing prompt chaining techniques with LLM APIs to systematically construct high-severity negative test scenarios, boundary validations, and precise expected error messages.

generate_test_cases.py Python 
import openai

def generate_negative_test_cases(prompt: str) -> str:
    """Systematically constructs negative validation scenarios via prompt chaining."""
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "You are a Senior QA Test Architect. Formulate exhaustive negative test cases and expected error states."},
            {"role": "user", "content": prompt}
        ],
        temperature=0.2
    )
    return response.choices[0].message.content

# Example Execution
prompt = "Formulate negative test cases with boundary conditions for multi-factor login."
print(generate_negative_test_cases(prompt))

By enforcing low temperature and persona-primed prompt templates, this pattern produces deterministic, high-coverage boundary scenarios that standard manual test drafting frequently overlooks.
